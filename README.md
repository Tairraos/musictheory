# 姐弟厨师团 --- 乐理课

一个可以"动手弄响"的乐理互动课。不啃符号、不背公式，每一块内容都能点、能听、能改参数——
大调小调、七个调式、五声、和弦进行、行板、拍号、移调、听感配方，主流的音乐语言一次玩透。

## 运行

整个工程只有一个文件 `index.html`：无依赖、无构建、无网络请求（插画已内嵌）。
直接双击用浏览器打开即可；或起个本地服务：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

建议用桌面端 Chrome / Edge / Safari，手机竖屏同样适配（底部有常驻钢琴）。

## 内容（13 节）

| 节 | 内容 |
|---|---|
| 00 | 先弄响一架钢琴（点键即出声，选调即亮键） |
| 01 | 半音、全音与音程 |
| 02 | 大调与小调 |
| 03 | 七个调式（同串白键，换个音起步） |
| 04 | 五声音阶与偏音 |
| 05 | 和弦与和声 |
| 06 | 终止式与副歌抬升 |
| 07 | 速度（行板在这） |
| 08 | 拍号与节奏 |
| 09 | 移调与调号 |
| 10 | 心情 / 天气 / 温度 |
| 11 | 转调与七和弦 |
| 12 | 速查表 |

## 技术要点

- **Web Audio API 实时合成**：每个音 = 3 个振荡器（基频 / 八度 / 十二度泛音）+ 低通包络，
  无任何音频文件
- **键盘音域 C3–D7**：可视窗固定两八度（C4–B5），超出部分左右溢出；
  播放时发声键自动贴边缘进入视口，键灭后 0.5s 滑回；支持鼠标/触屏拖动平移
- **透明底插画**：页头插图 PNG 带 alpha 通道，直接融入页面底色

## 部署

静态单文件，任何静态托管都能发（入口即 `index.html`）：Vercel、Netlify、GitHub Pages 等。

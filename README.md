# 姐弟厨师团 —— 乐理课

一个可以"动手弄响"的乐理互动课。不啃符号、不背公式，每一块内容都能点、能听、能改参数——
大调小调、七个调式、五声、和弦进行、行板、拍号、移调、听感配方，主流的音乐语言一次玩透。

## 运行

工程已从单文件拆分为多文件（HTML / CSS / JS / 图片分离），仍是**零运行时依赖**的静态站，
无构建、无网络请求（声音全部由浏览器实时合成，插图是本地 PNG）。

直接双击 `index.html` 用浏览器打开即可；或起个本地服务：

```bash
npm start            # 等价于 python3 -m http.server 8000
# 打开 http://localhost:8000
```

建议用桌面端 Chrome / Edge / Safari，手机竖屏同样适配（底部有常驻钢琴）。

## 目录结构

```
musictheory/
├── index.html               # 页面骨架：13 节 <section> + 底栏钢琴 + 脚本装载
├── package.json             # 项目信息与脚本（start / test）
├── css/
│   └── main.css             # 全站样式（原 <style> 拆出，仅补注释未改规则）
├── js/
│   ├── data.js              # 课程数据层：调式/音程/进行/速度/拍号/场景配方……
│   ├── utils.js             # 工具层：$ / MIDI↔音名↔频率 / triad / spellUp
│   ├── audio.js             # 音频引擎层：Web Audio 合成 + 节拍器
│   ├── keyboard.js          # 钢琴键盘组件：绘制、亮键、闪灯、视口管理
│   ├── svg.js               # 示意图层：音阶图/旋律图/调式全貌/和弦对比……
│   ├── playback.js          # 播放调度层：序列排程、进行/终止式/场景播放
│   ├── sections.js          # 交互装配层：逐节生成 chips/表格并绑定播放
│   └── app.js               # 入口层：全局状态 + init + 全局事件
├── assets/
│   └── images/
│       └── hero-art.png     # 页头插图（256×256 透明底 PNG）
└── tests/
    └── run-tests.js         # 自动化测试（jsdom 真实加载页面）
```

模块均为经典 `<script>`（非 ES Module），按上表顺序共享全局作用域——
**双击 index.html 也能离线跑**，不需要服务器。

## 测试

```bash
npm install     # 安装开发依赖 jsdom
npm test
```

测试用 jsdom 从磁盘加载真实页面，覆盖四类检查：

- **资源拆分**：外链 CSS / 8 个 JS 全部就位，插图已外链、无 base64 残留
- **页面装配**：13 节导航、两架键盘键数（C4–B5 与 C3–D7）、各表格行数、SVG 方块数
- **乐理函数**：音名 / MIDI / 频率 / 三和弦 / 罗马数字 / 音名拼写
- **交互冒烟**：桩 AudioContext 下点播各节播放按钮，验证出声 + 点亮链路无报错

## 技术要点

- **Web Audio API 实时合成**：每个音 = 3 个振荡器（基频 / 八度 / 十二度泛音）+ 低通包络，
  雨声/风声 = 噪声缓冲过滤波器；无任何音频文件
- **键盘音域 C3–D7**：可视窗固定两八度（C4–B5），超出部分左右溢出；
  播放时发声键自动贴边缘进入视口，键灭后 0.5s 滑回；支持鼠标/触屏拖动平移
- **透明底插画**：页头插图 PNG 带 alpha 通道，直接融入页面底色
- **注释密度**：所有 js/css 文件按"文件头 → 分区横幅 → 函数级注释"三级写满，
  含历史踩坑记录（如键盘音域必须实测、pointer capture 会吞 click 等）
